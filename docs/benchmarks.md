<ul class="bm-list">
  <li class="bm-item">
    <p class="bm-name">Screen Tester</p>
    <p class="bm-sent">Walks through dead pixels, burn-in, colour, uniformity, touch and refresh rate on the phone itself.</p>
    <p class="bm-sent">Use it after the built-in Screen page if you want a guided score to compare two phones.</p>
    <a class="bm-link" href="https://screentester.io/mobile-screen-test/" target="_blank" rel="noopener">Open Screen Tester</a>
  </li>
  <li class="bm-item">
    <p class="bm-name">Touch Screen Test</p>
    <p class="bm-sent">Paints a grid and lights each square your finger reaches, so an unreachable strip shows up immediately.</p>
    <p class="bm-sent">Slide slowly along every edge. A square that stays blue is a dead zone.</p>
    <a class="bm-link" href="https://www.onlinemictest.com/touch-screen-test/" target="_blank" rel="noopener">Open Touch Screen Test</a>
  </li>
  <li class="bm-item">
    <p class="bm-name">Basemark Web 3.0</p>
    <p class="bm-sent">Measures web graphics performance.</p>
    <p class="bm-sent">Add ?battery=1 to the end of the URL to turn on its battery drain loop, and save the results link before the battery dies.</p>
    <a class="bm-link" href="https://web.basemark.com/" target="_blank" rel="noopener">Open Basemark Web 3.0</a>
  </li>
  <li class="bm-item">
    <p class="bm-name">Dead Pixel Test</p>
    <p class="bm-sent">Full-screen solid colours for spotting stuck and dead pixels, with no setup.</p>
    <p class="bm-sent">Wipe the panel first, then look at each colour from a hand's width away.</p>
    <a class="bm-link" href="https://deadpixeltest.org/" target="_blank" rel="noopener">Open Dead Pixel Test</a>
  </li>
  <li class="bm-item">
    <p class="bm-name">Speedtest by Ookla</p>
    <p class="bm-sent">Gives a plain throughput number when the store wifi is in question.</p>
    <p class="bm-sent">Run it twice and use the lower of the two numbers.</p>
    <a class="bm-link" href="https://www.speedtest.net/" target="_blank" rel="noopener">Open Speedtest</a>
  </li>
</ul>

<p style="margin-top:16px;font-size:16px">If a link does not load, search for the tool by name.</p>

<ul class="bm-check">
  <li>Do this on the store wifi before you buy.</li>
  <li>Compare the same page on your current phone.</li>
  <li>Note the screen brightness you used.</li>
  <li>Run each test twice and keep the worse result.</li>
  <li>Save or screenshot any result you want to keep, since nothing is stored here.</li>
</ul>
